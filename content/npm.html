Install @pulse/sdk#

npm install github:DevMello/pulse#sdk-dist
# or: pnpm add github:DevMello/pulse#sdk-dist · yarn add github:DevMello/pulse#sdk-dist

@pulse/sdk isn't published to the npm registry yet. The sdk-dist branch holds the prebuilt package and is kept in sync automatically on every release, so installing straight from GitHub gets you the exact same thing a registry install would — same package name, same import paths.

The package ships ESM and CJS builds with TypeScript declarations, has no runtime dependencies, and is marked side-effect-free so bundlers tree-shake anything you don't import. It reimplements the transport rather than loading px.js, so bundler users pay for zero extra network requests.

Core API#

Five functions, all importable from @pulse/sdk and re-exported from every framework entry point.

init(config)

init(config: PulseConfig): void

Configure Pulse and — unless you opt out — start automatic pageview tracking. It's safe to call more than once: React Strict Mode and hot reload both do, and a second call rebinds cleanly rather than doubling every pageview. This is the classic way an SDK silently reports 2× traffic in development, and Pulse is built not to.

import { init } from '@pulse/sdk';

init({
  key: 'YOUR_INGEST_KEY',
  host: 'https://your-pulse.vercel.app',
  autoPageviews: true,     // default
  respectDnt: false,       // default
  trackLocalhost: false,   // default
  exclude: ['/admin*'],    // default: []
});

track(name, props?)

track(name: string, props?: EventProps): void

Record a custom event. Passing the name 'pageview' is a shortcut that routes to pageview() (and gets its dedupe).

import { track } from '@pulse/sdk';

track('signup', { plan: 'pro', referrer: 'newsletter' });
track('feature_used', { name: 'export', count: 3 });
track('cta_click');   // props optional

trackRevenue(name, revenue, props?)

trackRevenue(name: string, revenue: Revenue, props?: EventProps): void

Sugar over track(). These two calls produce exactly the same payload:

trackRevenue('purchase', { amount: 29, currency: 'USD' });
track('purchase', { revenue: { amount: 29, currency: 'USD' } });

pageview(url?)

pageview(url?: string): void

Record a pageview. Defaults to window.location.href. Deduped against the last URL sent, so calling it twice for the same URL is a no-op. Pass an explicit URL when your router knows the destination before the address bar does.

import { pageview } from '@pulse/sdk';

pageview();                       // current URL
pageview('https://app.dev/pricing'); // explicit

teardown()

teardown(): void

Stop automatic tracking, unbind the route listeners, restore the original History methods, and forget the config. The framework adapters call this for you on unmount; you rarely need it directly.

Configuration options#

The object passed to init() (and to every framework helper).

OptionTypeDefaultDescription
key requiredstring—The project's public ingest key. Safe to ship in client code.
host requiredstring—Your Pulse deployment's origin, e.g. https://pulse.example.com. A trailing slash is trimmed for you.
autoPageviewsbooleantrueTrack pageviews automatically on History / hash route changes.
respectDntbooleanfalseDrop events from browsers sending DNT / GPC.
trackLocalhostbooleanfalseTrack localhost and file://. Off keeps dev traffic out of your data.
excludestring[][]Paths to skip. A trailing * is a prefix match, e.g. '/admin*'.

TypeScript types#

All exported from every entry point.

interface PulseConfig {
  key: string;
  host: string;
  autoPageviews?: boolean;   // default true
  respectDnt?: boolean;      // default false
  trackLocalhost?: boolean;  // default false
  exclude?: string[];        // default []
}

interface Revenue {
  amount: number;            // major units — 29 means $29.00
  currency?: string;         // ISO 4217, default 'USD'
}

type EventProps = Record<string, string | number | boolean | Revenue | undefined>;

Event properties must be scalars — string, number, or boolean — plus the special revenue object. Nested objects and arrays are dropped server-side to keep the events table lean.
