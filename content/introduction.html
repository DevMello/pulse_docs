Pulse SDK · Documentation

Track pageviews, events & revenue in one line.

The Pulse SDK is how your site talks to your self-hosted analytics. Drop in a ~1 KB script tag, or install the typed @pulse/sdk package with first-class adapters for React, Vue and Svelte. No cookies, no consent banner, nothing stored on the device.

What the SDK does#

Every Pulse integration boils down to sending three kinds of signal to your collector: pageviews, custom events, and revenue. The SDK is a thin, fire-and-forget transport for those signals — enrichment (device, browser, country, referrer grouping) all happens server-side, so the client stays tiny and leaks nothing.

Pageviews

Tracked automatically on first load and on every SPA route change, deduped against the last URL sent.

Custom events

Any named event with optional scalar properties — signups, clicks, feature usage, funnel steps.

Revenue

Attach an amount and currency to any event. It lands in the same pipeline as your Stripe webhooks.

Script tag vs. npm package#

There are two ways to install Pulse, and the plain script tag does everything the SDK does. The npm package is optional sugar — reach for it only when you want typed helpers and route tracking wired into a framework.
