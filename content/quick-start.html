Quick start#

Grab your project's public ingest key from the Pulse dashboard (Project → Settings), then pick a path below. Your first pageview should land within seconds.

Option A — the script tag

Paste this before </body>. That is the entire integration.

<script defer data-key="YOUR_INGEST_KEY" src="https://your-pulse.vercel.app/px.js"></script>

Swap your-pulse.vercel.app for your own deployment's origin, and YOUR_INGEST_KEY for the key shown in the dashboard. The key is public by design — it ships in client code, and the domain allow-list (not the key) is what stops forged events.

Option B — the npm package

npm i @pulse/sdk
import { init, track, trackRevenue } from '@pulse/sdk';

init({
  key: 'YOUR_INGEST_KEY',
  host: 'https://your-pulse.vercel.app',
});

// Custom event
track('signup', { plan: 'pro' });

// Revenue
trackRevenue('purchase', { amount: 29, currency: 'USD' }, { plan: 'pro' });

Calling init() starts automatic pageview tracking immediately. Everything else — events, revenue, framework helpers — builds on top of that.
