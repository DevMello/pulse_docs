Quick start#

Grab your project's public ingest key from the Pulse dashboard (Project → Settings), then pick a path below. Your first pageview should land within seconds.

Option A — the script tag

Paste this before </body>. That is the entire integration.

<script defer data-key="YOUR_INGEST_KEY" src="https://your-pulse.vercel.app/px.js"></script>

Swap your-pulse.vercel.app for your own deployment's origin, and YOUR_INGEST_KEY for the key shown in the dashboard. The key is public by design — it ships in client code, and the domain allow-list (not the key) is what stops forged events.

Option B — the npm package

Not on the npm registry yet — install straight from GitHub instead:

npm install github:DevMello/pulse#sdk-dist
# or: pnpm add github:DevMello/pulse#sdk-dist · yarn add github:DevMello/pulse#sdk-dist
import { init, track, trackRevenue } from '@pulse/sdk';

init({
  key: 'YOUR_INGEST_KEY',
  host: 'https://your-pulse.vercel.app',
});

// Custom event
track('signup', { plan: 'pro' });

// Revenue
trackRevenue('purchase', { amount: 29, currency: 'USD' }, { plan: 'pro' });

Calling init() starts automatic pageview tracking immediately. Everything else — events, revenue, framework helpers — builds on top of that.

Option C — let your AI do it

Pulse ships an agent skill — a playbook in the open Agent Skills format that teaches AI coding tools (Claude Code, Cursor, Codex and friends) how to integrate Pulse correctly. Install it in the project you want to track:

npx skills add DevMello/pulse --skill add-pulse-analytics

Then ask your agent in plain English:

Add Pulse analytics to this app. My instance is at
https://your-pulse.vercel.app and the ingest key is YOUR_INGEST_KEY.

The skill walks the agent through the whole job: detect your framework, pick the script tag or @pulse/sdk, wire the right adapter (React, Next.js App Router, Vue, Svelte/SvelteKit), avoid the classic double-pageview mistakes, and verify events actually reach your collector before calling it done.
